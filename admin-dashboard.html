Import SIR Results from Excel

SIR master format: one row per test. PCM/PCB subjects and A/C/W/S are read dynamically. Question-wise responses can be imported from a second sheet named Question Responses.
Supported columns: Student UID / Roll Number, Student Name, Batch, Stream, Exam Name, Date/Mode, Marks, PHY, CHEM, MATH or BIO, %TAGE, %TILE, Batch Rank, Overall Rank, Status. Subject cells may contain marks plus A/C/W/S. AB is preserved as absent, never converted to zero.
Optional question sheet columns: Student UID / Roll Number, Exam Name, Date, Subject, Question No, Student Answer, Correct Answer, Result (Correct/Wrong/Skipped), Marks.
